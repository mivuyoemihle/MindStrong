
# Mind Strong

## Website Project

Mind Strong is a website focused on men's mental health and mental wellbeing.

The website provides general information about mental health, support options and useful resources. The aim is to make mental health information simple, accessible and easy to understand.

## Website Pages

The website contains the following pages:

- Home
- About Us
- Support
- Resources
- Enquiry
- Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git and GitHub
